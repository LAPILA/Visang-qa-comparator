검사 설정

안전한 범위부터

프로젝트를 선택하면 등록한 환경을 아래 A/B 환경 주소에서 고를 수 있습니다. 프로젝트 설정은 로컬 PostgreSQL에 저장됩니다.

허용된 경로와 동작만 실행합니다. 사용자 지정 URL은 시작 페이지를 기준으로 설정합니다.

동일 제품의 A/B를 각각 검사한 뒤 승인된 페이지와 영역을 비교합니다.

프로젝트를 선택하면 해당 프로젝트의 환경을 불러옵니다. 환경 선택은 URL과 표시 이름만 바꾸며 검사를 시작하지 않습니다. 직접 입력도 가능합니다.

환경 이름은 제품과 별도로 정하는 표시용 이름이며 자유롭게 수정할 수 있습니다. 이름을 바꿔도 URL은 변경되지 않습니다.

시작 페이지 쌍은 경로나 제목이 달라도 대응시킵니다. 이후 발견한 다른 페이지는 별도 매칭 규칙으로 비교합니다. 서로 다른 기능의 시작 페이지라면 체크를 해제하세요.

조건에 맞는 현재 화면을 읽어 검사합니다. 데이터·화면을 임의로 변경하지 않습니다. 기대값이 없으면 REVIEW, 사전 조건을 만족하지 못하면 BLOCKED로 기록합니다.

임계값은 이번 실행의 시각 차이 판정에 적용됩니다. 결과를 좁히는 차이율 필터는 검사 후 별도로 사용할 수 있습니다. 현재 등록 기능 시나리오는 합성 데모에서 제공됩니다.

          
          

          
확대 탐색은 선택한 각 시작 URL의 출처(scheme·host·port) 내부 읽기 링크에 한합니다. 다른 환경·외부 호스트, 계정·개인정보·쓰기 동작, POST, 다운로드와 API·데이터 파일은 제외하고 페이지·깊이·동작·시간 한도를 유지합니다.

담당자·프로필·환경별로 이 PC의 브라우저에만 저장합니다. 체크를 해제하면 현재 담당자·프로필의 저장된 아이디를 지웁니다.

            

          


          

            고급 설정 · 페이지 매핑, 영역, 허용 동작
            

              
기본 탐색은 시작 페이지와 명시한 별칭·승인 경로만 허용합니다. 환경 내부 읽기 전용 링크 탐색을 선택하면 각 출처 내부의 안전한 읽기 링크로 범위를 확대합니다. 추가 동작은 검토 후 등록하세요. 전체 허용(*)이나 목적이 불명확한 동작을 허용하지 않습니다. 정적 CDN과 탐색·API·인증 호스트는 용도에 맞게 나누어 등록합니다.

              
              
              
필요한 정확한 호스트를 한 줄에 하나씩 입력합니다. 호스트 등록만으로 모든 경로·동작을 허용하지는 않습니다.

              
              
스크립트·스타일·이미지·폰트 등 정적 자원 요청에만 쓰는 정확한 호스트입니다. 이 목록은 페이지 이동·API 호출·로그인 호스트를 허용하지 않습니다.

              
              
              
              
화면의 이름·계정 헤더 등 가릴 요소의 선택자를 문자열 배열로 입력합니다(최대 30개). 비밀번호 입력 마스킹은 기본 유지됩니다. 개인정보를 자동으로 찾아주는 기능은 아니므로 캡처 전 대상을 확인하세요.
